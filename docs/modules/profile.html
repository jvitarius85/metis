Foundation module

Profile

Give each person a clear place to manage their own account, security methods, and notification preferences.

What it helps your team do

  • Keep personal profile information current.
  • Manage account security methods, including passkeys where enabled.
  • Review and control personal notification preferences.

Good to know

Profile is required because it supports each person’s account context in Metis.
