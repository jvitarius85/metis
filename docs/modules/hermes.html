Operations module

Hermes

A permission-aware operational assistant for monitoring system health, reviewing recommendations, and running approved actions.

What it helps your team do

  • Review system-health information and operational recommendations.
  • Use sessions, reports, and memory to organize assistant-driven work.
  • Run actions only after the appropriate approval and permission checks.

Good to know

Hermes operates within Metis permissions and protected-action controls; it is not an unrestricted automation layer.
